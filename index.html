CodeSync

Komanda üçün real-time fayl sinxronizasiyası və versiya nəzarəti

Setup

Bu ad bütün fayl əməliyyatlarında göstəriləcək. Komanda üzvləri arasında unikal olmalıdır.

File System Access API əlçatan deyil

Səbəb: —

Həll yolları (tövsiyə olunan):

  1. HTTPS istifadə edin — CODESYNC_HTTPS=1 node server.js ilə self-signed cert, sonra brauzerdə "Advanced - Proceed" klikləyin
  2. cloudflared tunnel — cloudflared tunnel --url http://localhost:3000
  3. localhost üzərindən açın (yalnız server maşınında)
  4. Chrome flag: chrome://flags/#unsafely-treat-insecure-origin-as-secure

Diqqet: Virtual rejim yalnız oxuma üçündür — fayllar yaddaşda saxlanılır, diskə yazılmır. Real-time sinxronizasiya üçün yuxarıdakı 1 və ya 2-ci variantı seçin.

Bu qovluqdakı bütün text fayllar sinxronlaşacaq. node_modules, .git, _snapshots, _vcs, _conflicts və binary fayllar ötürülür.
Snapshotlar broker tərəfindən _snapshots/ qovluğunda, commitlər isə _vcs/ qovluğunda saxlanılır. Qoşulduqdan sonra commit edə, branch yarada və tarixçəni görə bilərsiniz.
